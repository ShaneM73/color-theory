# Color Theory Lab

### 🔗 Live app: **https://shanem73.github.io/color-theory/**

**Designer and main contributor:** Prof. Xin (Shane) Miao, Missouri State University ([@ShaneM73](https://github.com/ShaneM73))

A teaching module for **GEO 360 Aerial Photo Interpretation** and **GEO 551/651 Remote Sensing** at Missouri State University. It is an interactive, single-file walkthrough of color theory in eight steps:

1. **Additive** color (mixing light, RGB)
2. **Subtractive** color (mixing pigment, CMY/CMYK)
3. **Color wheels** (RYB, RGB, CMY, perceptual OKLCH)
4. **Hue, saturation, brightness**
5. **Color harmony** schemes
6. **Color models** with rotatable 3D solids (RGB cube, HSB cylinder & cone, HSL double cone)
7. **Perception** (simultaneous contrast, Munker–White)
8. **The Dress** (2015) as a case study in color constancy

No build step. `index.html` is the whole app; open it locally or serve it from any static host.
It is published with GitHub Pages from the `main` branch (root).
